# Редактирование контента

## Где что менять

| Что изменить                                                | Файл                             |
| ----------------------------------------------------------- | -------------------------------- |
| Названия, краткие описания, условия, технические требования | `content/integrations.ts`        |
| Развёрнутые описания физических интеграций                  | `content/details.ts`             |
| Месячные охваты цифровых форматов                           | `content/digital-reach.json`     |
| Адреса ресторанов и статус открытия                         | `content/locations.json`         |
| Размеры и сведения о фотографиях                            | `content/media.json`             |
| Фразы после «Мы делаем»                                     | `components/home-experience.tsx` |
| Общие стили и адаптивность                                  | `app/globals.css`                |
| Заголовок и описание сайта                                  | `app/layout.tsx`                 |

## Контакты

Контакты находятся в `components/contact-options.tsx`, `components/site-shell.tsx` и `app/contacts/page.tsx`. При смене email или телефона обновите все эти места. В `href` телефон записывается в международном формате без пробелов. Ссылки на email выбранной интеграции заполняют тему письма.

## Фотографии

Файлы хранятся в `public/media/imageN.webp`. Числовые идентификаторы связывают изображение с `image` и `gallery` в описании формата. Имена сохранены для сопоставления с исходной презентацией.

При добавлении фотографии сохраните пропорции, обновите данные в `content/media.json` и проверьте её отображение на телефоне. Не увеличивайте небольшие исходники без необходимости.

## Форматы и охваты

Порядок значений в `content/digital-reach.json` соответствует порядку `digitalBase` в `content/integrations.ts`. Если добавляете или переставляете цифровой формат, синхронно обновите оба файла.

При изменении списка физических форматов обновите главную: массив фраз, счётчик направлений и навигацию. После изменений выполните проверки из README.

## Коммерческая информация

Текущая версия не содержит расценок. Стоимость обсуждается по email или телефону. Числа в фактах описывают охваты, количество ресторанов, тиражи или сроки. Не переносите цены из исходных таблиц в код, документацию или историю Git без отдельного решения владельца.

Источники и различия между программами описаны в [CONTENT_NOTES.md](CONTENT_NOTES.md).
