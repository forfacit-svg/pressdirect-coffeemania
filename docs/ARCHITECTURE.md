# Архитектура

Приложение написано на React и TypeScript. Маршрутизация использует структуру App Router; Vinext собирает приложение через Vite для Cloudflare Workers. `next` обеспечивает совместимые API и типы. Стандартная команда сборки проекта — `pnpm build`, а не `next build`.

## Слои

| Слой          | Ответственность                                       |
| ------------- | ----------------------------------------------------- |
| `app/`        | Подбор данных по маршруту, метаданные, общая оболочка |
| `components/` | Повторно используемое представление и интерактивность |
| `content/`    | Типизированные форматы и статические данные           |
| `public/`     | Фотографии, шрифты, иконка сайта                      |

Данные хранятся в исходниках. CMS, база данных, серверная отправка писем и пользовательские аккаунты не используются.

## Маршруты

| Путь                           | Содержание                                |
| ------------------------------ | ----------------------------------------- |
| `/`                            | Главная и выбор интеграции                |
| `/integrations/bill-folder`    | Полоса в папке для счёта                  |
| `/integrations/collaborations` | Гастрономические коллаборации             |
| `/integrations/press-stands`   | Буклеты и каталоги                        |
| `/integrations/delivery`       | Вложение в доставку и заказы «с собой»    |
| `/integrations/airport`        | Интеграции в Шереметьево                  |
| `/integrations/digital`        | Обзор цифровых интеграций                 |
| `/integrations/digital/[slug]` | Семь страниц цифровых форматов            |
| `/coffeemania`                 | О возможностях сети                       |
| `/addresses`                   | Адреса ресторанов                         |
| `/contacts`                    | Email и телефон, включая выбранный формат |

Неизвестные идентификаторы форматов возвращают страницу «Не найдено».

## Главная

`components/home-experience.tsx` управляет активным форматом. Автопереключение выполняется каждые пять секунд, приостанавливается при наведении на текст или фотографию, фокусе внутри витрины или открытом выборе формата и учитывает `prefers-reduced-motion`. Ручной выбор сохраняется в `sessionStorage` текущей вкладки.

Навигация использует обычные ссылки. Кнопки с иконками имеют доступные текстовые названия. Ссылка «К содержанию» помогает перейти к основному блоку с клавиатуры.

## Оформление

`app/globals.css` содержит цвета, сетки, состояния и адаптивные правила. Фон светлый, основной текст графитовый, фирменный акцент — `#b82236`. Заголовки набраны Manrope 500, основной текст — Golos Text 400. Файлы шрифтов загружаются с сайта.

## Движение при прокрутке

`components/site-motion.tsx` подключён в корневой оболочке. Он однократно раскрывает блоки с `data-reveal` через IntersectionObserver и смещает крупные фотографии с `data-parallax` через requestAnimationFrame. Подробности и ограничения — в [MOTION.md](MOTION.md).
