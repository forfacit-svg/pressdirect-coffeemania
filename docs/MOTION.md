# Scroll Reveal и Parallax

Движение дополняет редакционную компоновку и не меняет порядок чтения страниц.

- Заголовки разделов, описания, контакты и галереи появляются один раз при прокрутке: небольшое смещение вверх и плавное проявление.
- Карточки и фотографии в одной строке имеют короткую последовательную задержку. Для строк адресов и форматов амплитуда меньше.
- Витрина, обложки интеграций и большая фотография на странице сети получают параллакс до 12–20 px. Двигается вся фотография, поэтому её кадрирование и пропорции не меняются.
- На экранах до 760 px и устройствах без точного указателя параллакс отключён. Scroll Reveal остаётся более коротким и спокойным.
- При `prefers-reduced-motion: reduce` оба эффекта отключены. Смена настройки учитывается без перезагрузки.

## Подключение

`SiteMotion` установлен один раз в `app/layout.tsx`. Компонент работает с атрибутами существующих блоков:

| Атрибут                  | Назначение                                                    |
| ------------------------ | ------------------------------------------------------------- |
| `data-reveal`            | Обычное появление блока                                       |
| `data-reveal="row"`      | Сокращённое смещение для строки                               |
| `data-reveal-delay="80"` | Задержка в миллисекундах; ограничена 180 ms                   |
| `data-parallax="16"`     | Максимальное смещение фотографии в пикселях; ограничено 20 px |

Размещайте появление на одном уровне: не нужно одновременно анимировать большой контейнер и все его дочерние блоки. Не добавляйте параллакс к тексту, формам и элементам навигации.

## Доступность и производительность

Контент виден в исходном HTML. Если JavaScript или IntersectionObserver недоступны, страница остаётся читаемой. Уже видимые блоки не скрываются при запуске или восстановлении позиции прокрутки. Фокус с клавиатуры немедленно раскрывает нужный блок. При печати всё содержимое отображается без смещений.

Параллакс обновляет только находящиеся рядом с экраном фотографии. Обработчики прокрутки пассивные; изменения объединяются в один requestAnimationFrame. Анимации не перехватывают прокрутку. При смене страницы обработчики и наблюдатели освобождаются.
