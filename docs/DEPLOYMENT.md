# Сборка и публикация

## Текущий сайт

Рабочая версия: https://pressdirect-coffeemania.forfacit.chatgpt.site

Сайт опубликован через Sites и открыт для просмотра по ссылке. Идентификатор существующего проекта находится в `.openai/hosting.json`. Это идентификатор ресурса, а не ключ доступа.

## Локальная проверка production-сборки

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm format:check
pnpm build
pnpm start
```

Сборка создаёт каталог `dist/`, включая конфигурацию Worker `dist/server/wrangler.json`. Команда `start` запускает его локально через Wrangler. Результаты сборки, зависимости и служебные состояния не добавляются в Git.

## Обновление опубликованной версии

GitHub хранит подготовленную копию исходников. Push в этот репозиторий сам по себе не обновляет работающий сайт.

Чтобы обновить текущую публикацию, передайте изменения в рабочий проект Sites, повторите проверки и опубликуйте новую версию того же проекта. Существующий публичный доступ следует сохранить. GitHub Actions выполняет только проверки и не требует токенов публикации.

Привязка `pressdirect.ru` выполняется отдельно через настройки домена и DNS. Загрузка исходников в GitHub не меняет DNS и не заменяет текущую публикацию на основном домене.

## Перенос

Приложение использует Worker-сборку Vinext. Для другой платформы потребуется её совместимый адаптер и отдельная конфигурация публикации. Текущий проект не является статическим экспортом для GitHub Pages.

## Переменные окружения

В текущей версии нет обязательных переменных окружения и секретов приложения. Если позднее появятся внешние сервисы, храните ключи в настройках хостинга; для разработчиков добавляйте только шаблон с пустыми значениями.
