# Прессдирект × Кофемания

Сайт рекламных и партнёрских интеграций в «Кофемании»: выбор формата, подробные описания, фотографии, технические требования и адреса ресторанов.

**[Открыть сайт →](https://pressdirect-coffeemania.forfacit.chatgpt.site)**

React · TypeScript · Vinext · Tailwind CSS · Cloudflare Workers

## Возможности

- Шесть направлений интеграций и семь отдельных цифровых форматов.
- Главная с меняющейся фразой «Мы делаем…», фотографиями и переходами на страницы форматов.
- Поддержка свайпов, клавиатуры, паузы и системной настройки уменьшения движения.
- Фотографии из презентации в WebP, локальные шрифты Manrope и Golos Text с кириллицей.
- Адресная программа: городские рестораны и Шереметьево.
- Email с выбранным форматом в теме письма и телефон для обсуждения размещения. Расценки не публикуются.

## Быстрый старт

Понадобятся **Node.js 24** и **pnpm 11.25.0**. Точные версии зависимостей зафиксированы в `pnpm-lock.yaml`.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Сайт откроется на `http://localhost:5173`. Для локального запуска не нужны API-ключи, база данных или файл `.env`.

```bash
pnpm typecheck     # TypeScript
pnpm lint          # ESLint
pnpm format:check  # единое оформление исходников
pnpm build         # production-сборка
pnpm start         # локальный запуск собранного Worker
```

`pnpm start` выводит адрес в терминал. Команда `pnpm format` автоматически форматирует исходники.

## Структура проекта

| Каталог         | Назначение                                                            |
| --------------- | --------------------------------------------------------------------- |
| `app/`          | Страницы, маршруты, общие стили и метаданные                          |
| `components/`   | Шапка, подвал, переключатель форматов, страницы интеграций и контакты |
| `content/`      | Описания интеграций, адреса, охваты и данные изображений              |
| `public/media/` | Фотографии из презентации, оптимизированные в WebP                    |
| `public/fonts/` | Локальные шрифты и лицензии SIL OFL                                   |
| `docs/`         | Архитектура, редактирование контента, источники и публикация          |
| `scripts/`      | Запуск, установка и сборка в поддерживаемых средах                    |
| `build/`        | Интеграция сборки с Sites и лицензия плагина                          |
| `vendor/`       | Внешние CSS-ресурсы с лицензиями                                      |
| `.github/`      | Проверки pull request и шаблон описания изменений                     |
| `.openai/`      | Конфигурация существующей публикации Sites                            |

## Проверки

GitHub Actions запускает проверку типов, ESLint, форматирование и сборку при push в `main` и в pull request. Workflow проверяет код и не публикует сайт автоматически.

## Материалы и лицензии

В репозитории есть все используемые сайтом фотографии и шрифты. Исходные презентации, таблицы с расценками, локальные кэши и готовые сборки в него не включены.

Фотографии, тексты, товарные знаки и логотипы не получают открытую лицензию автоматически. Их использование согласовывается с правообладателями. Лицензии внешних компонентов находятся рядом с соответствующими файлами в `public/fonts/`, `build/` и `vendor/`.
