# Работа с проектом

1. Создайте ветку от `main`, например `feat/new-integration` или `fix/mobile-header`.
2. Внесите изменения в соответствующий слой: контент, компоненты или страницы.
3. Выполните `pnpm format`, `pnpm typecheck`, `pnpm lint` и `pnpm build`.
4. Проверьте затронутые страницы на широком и узком экране. Для интерактивных элементов проверьте клавиатуру, фокус и ссылки.
5. Откройте pull request с описанием результата и проведённых проверок.

Не добавляйте в Git `node_modules`, `dist`, `.env`, локальные кэши, токены, исходные коммерческие таблицы и временные архивы. Для фотографий и шрифтов сохраняйте сведения об источнике и лицензиях.

Публикация сайта выполняется отдельно от слияния pull request. См. [DEPLOYMENT.md](docs/DEPLOYMENT.md).
